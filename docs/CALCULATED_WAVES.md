# Calculated incident and disturbed wave example

Run `run_gui.py` and choose **File → Load calculated wave preview example**. The
ANY3dView canvas immediately shows two captured bodies with incident plus body
diffraction. The Waves dropdown switches between **Incident waves (without
disturbance)** and **Incident + body disturbance**. Play/Pause controls animate
the stored field; the bodies stay fixed. GPU is preferred by default, with
explicit software fallback in View.

This example contains a real Capytaine 3.0.0 diffraction calculation: two bodies,
28 immersed panels, 801 retained surface nodes, omega=1.4 rad/s, incident amplitude
0.3 m, propagation heading0°, water depth20 m. Loading reads the packaged arrays
and verifies their seal and producing-project/request identity. It does not import
or execute Capytaine. The public ANYloads/ANYhydro wave interfaces are needed to
validate and evaluate stored arrays; matched local packages are in the tested GUI
environment.

The stored incident and scattered complex elevations use `exp(-i omega t)`.
The disturbed elevation is their sum at the displayed time; incident mode uses
the incident array alone. Capytaine's scattered field is scaled once by incident
amplitude and phase. Switching modes or renderer preserves captured body poses.
Selecting another model/replay frame or changing manual wave inputs invalidates
the preview. Saving the project saves its model; this packaged wave example can
be loaded again from File. Arbitrary preview-field project persistence is pending.

**Calculate body disturbance** calculates a new single-frequency fixed-body
preview in an isolated child, with at most two bodies/48 immersed panels/1024
surface points and a20-second deadline. Missing backend, cancellation, stale
inputs, crash or deadline cannot publish a completed field. The matched optional
backend is exactly Capytaine3.0.0. Loading the stored example needs no backend.

This is coarse visualization development evidence. It has no mesh convergence,
external reference or accuracy qualification. The loaded model's mechanical
coefficients are separate synthetic development data; they were not generated by
this diffraction calculation. Body-motion radiation, nonlinear free surfaces,
wave stretching and current-modified dispersion are not included. The saved
multi-frequency mechanical sea-state example currently supports incident display
only. Full scientific demonstrator acceptance remains open.

Actual Windows GPU observation used NVIDIA RTX3090Ti/OpenGL3.3; incident and
disturbed mesh positions match the authoritative stored arrays at1e-12. Software
fallback and return to GPU preserve poses/playback. The first historical attempt
timed out building a default Green-function table; that evidence remains intact.
The later successful attempt used public Delhommeau direct integration with zero
tabulation dimensions, the retained1001-point integration rule and one thread.
