## 6. Canonical conventions and invariants

These conventions must be written before implementation in `ANYhydro/docs/CONVENTIONS.md` and enforced by tests.

### 6.1 Coordinates and units

- SI units throughout.
- Right-handed global system.
- \(+Z\) upward.
- Mean free surface at \(z=0\).
- Water depth is positive downward as a scalar but seabed elevation is negative in global coordinates.
- Angles are radians internally.
- Wave headings are stored in one canonical propagation convention and converted only at backend boundaries.
- Rotations use right-hand-positive axes.
- Rigid DOF ordering is:

```text
surge, sway, heave, roll, pitch, yaw
```

### 6.2 Complex convention

The canonical phasor convention is:

\[
x(t)=\Re\{X e^{-i\omega t}\}.
\]

All backend outputs are normalized to this convention before entering `HydroDataset`.

### 6.3 Mechanical authority

- ANYsolver owns dry mass, center of gravity and inertia.
- Capytaine/HAMS-MREL own radiation, diffraction and hydrodynamic coefficients.
- Capytaine's automatically estimated rigid-body inertia is never used as production dry mass.
- Hydrostatic stiffness from a backend is accepted only after convention and reference-point validation.
- BEM coefficients are fixed around the equilibrium configuration.
- Store reference buoyancy, gravity and preload separately from incremental hydrostatic restoring; assemble each contribution once.
- Bind coefficients to the equilibrium geometry, frames and relevant physical settings. Changes invalidate dependent coefficients and cached results.

### 6.4 Full matrix preservation

For \(N\) bodies, hydrodynamic data are retained in the complete \(6N\)-DOF space.

Never discard:

\[
A_{ij}(\omega),\quad B_{ij}(\omega), \qquad i\ne j.
\]

Off-diagonal terms are part of the production model and must survive serialization, interpolation and time-domain conversion.

### 6.5 Hydrodynamic ownership

Every wetted entity has one primary hydrodynamic role:

```text
potential_flow
morison_full
none
```

An explicit optional `drag_correction` is separate from this primary role. It
supports documented drag-only loading on a BEM component or a drag-only entity.

Rules:

- a component in the BEM panel mesh cannot also receive full Morison inertia;
- potential-flow ownership plus a documented drag correction is permitted;
- full Morison already includes drag and cannot also receive the same correction;
- members omitted from the BEM mesh may receive full Morison loading;
- mooring lines are not included in the BEM body;
- buoyancy has an explicit single owner, independent of the optional drag correction;
- the validator rejects duplicate inertia, drag or buoyancy and ambiguous ownership.

**Amended surface/load contract (planned).** Extend the existing records with
three independent semantics rather than overloading structural element kind:

```text
surface_kind: body_boundary | thin_sheet | numerical_lid
primary_hydrodynamics: potential_flow | morison | none
viscous_correction: none | member_drag | plate_drag
```

`morison` retains the existing full-Morison meaning. Explicit migration maps old
`morison_full` accordingly; old `potential_flow`/`none` retain their meanings.
Map legacy drag corrections only when their recorded geometry/coefficient
convention identifies the correction unambiguously. Old hull and explicit lid
fields identify body_boundary and numerical_lid respectively. A structural shell,
open mesh or unclassified role is not enough to infer thin_sheet; refuse ambiguous
conversion. Preserve old project readability and IDs with versioned migration.

A potential-flow sheet cannot also receive full Morison inertia for the same
contribution. Optional plate drag must declare reference area, coefficient
normalization (including any one-half density factor), relative velocity,
projection/force direction and dissipative power; no arbitrary circular-member
equivalent diameter. A zero-thickness sheet contributes no displaced volume.
Physical plate mass belongs once to the existing dry-mass model; any explicitly
retained physical finite-thickness buoyancy correction has one declared owner.
Numerical lids carry no physical plate load, mass or buoyancy.

For oriented sheet normal n pointing from the minus side to the plus side,
define delta_p = p_minus - p_plus and net traction = delta_p * n. Integrate
force and (x - body_reference) cross traction on the midsurface, using the owning
body's work-conjugate DOF map. Reversing orientation must swap side labels and
delta_p sign so physical force/moment stay invariant. State phasor, pressure
units, side locations and total/diffraction/radiation decomposition explicitly;
do not confuse ordinary one-sided panel pressure with pressure jump.

Separate hull and plate coefficient calculations added together are only an
explicitly selected approximation with missing interactions recorded; they must
never be described as the fully coupled companion demonstrator.

Every body, DOF, panel mesh, member, line, attachment and result dataset has:

- coordinate-frame identity;
- schema version;
- checksum;

- explicit assumptions and warnings.

## 8. Coupled formulation

The global state is:

\[
q=
\begin{bmatrix}
q_{\mathrm{body}}\\
q_{\mathrm{line}}\\
q_{\mathrm{structural}}
\end{bmatrix}.
\]

For two rigid bodies:

\[
q_{\mathrm{body}}\in \mathbb{R}^{12}.
\]

The following is an equilibrium-referenced schematic equation, not a complete
finite-rotation residual. The adopted mechanical contract must supply coordinate
maps, geometric acceleration and gyroscopic terms where required. Here hydrostatic
coordinates are perturbations about the stored equilibrium; reference weight,
buoyancy and preload balance is handled explicitly during initialization.

The time-domain equation is:

\[
\begin{aligned}
\left(M_\mathrm{dry}+A_\infty+M_{\mathrm{Morison}}\right)\ddot q(t)
&+
\int_0^t K_r(t-\tau)\dot q(\tau)\,d\tau\\
&+
F_\mathrm{internal}(q,\dot q)
+
C_h q
+
F_\mathrm{link}
+
F_\mathrm{contact}\\
&=
F_\mathrm{exc}(t)
+
F_\mathrm{Morison,fluid}(t,q,\dot q)
+
F_\mathrm{external}.
\end{aligned}
\]

### 8.1 Radiation model

Use:

\[
F_\mathrm{rad}(t)
=
-A_\infty \ddot q(t)
-
\int_0^t K_r(t-\tau)\dot q(\tau)\,d\tau
\]

with:

\[
K_r(t)=\frac{2}{\pi}\int_0^\infty B(\omega)\cos(\omega t)\,d\omega.
\]

The implementation must:

- operate on the full coupled DOF matrix;
- retain cross-body memory terms;
- expose frequency truncation and window diagnostics;
- verify symmetry/reciprocity to a configured tolerance;
- diagnose negative dissipative eigenvalues;
- support deterministic fixed-step convolution;
- include the current-step velocity dependence in the iteration tangent;
- store kernel generation settings and residuals.

Direct convolution is the qualified first implementation. A passive state-space fit is a later optimization behind the same interface.

### 8.2 Excitation synthesis

For a seeded wave realization:

\[
F_\mathrm{exc}(t)
=
\Re\left\{
\sum_k
a_k
\hat F_\mathrm{exc}(\omega_k,\beta_k)
e^{-i(\omega_k t-\phi_k)}
\right\}
\]

using the canonical phase convention.

Exactly the same \((\omega_k,\beta_k,a_k,\phi_k)\) components must drive incident-wave Morison kinematics.

### 8.3 Morison loading

Use combined wave/current fluid velocity in relative-velocity drag. Do not add a
second current-drag force to that result. Report current's contribution using a
declared decomposition that sums exactly to the assembled force, including nonlinear
wave/current interaction. Distinct external current effects require their own
non-overlapping physical definition. State the fluid-acceleration convention for
the selected wave/current model.

For a circular member normal to its axis:

\[
f_M =
\rho A\,\dot u_n
+
\rho C_A A(\dot u_n-\dot v_n)
+
\frac12 \rho C_D D
|u_n-v_n|(u_n-v_n).
\]

The implementation shall keep the components separate:

```text
Froude-Krylov/inertia
added mass
drag
buoyancy
wave/current drag attribution (not an additional force)
```

Distributed force is mapped through the point kinematic Jacobian:

\[
Q_M=\int J^T f_M\,ds.
\]

### 8.4 Rigid attachment kinematics

For local attachment vector \(\rho\):

\[
x=r+R\rho,
\qquad
v=\dot r+\omega\times R\rho.
\]

The exact attachment Jacobian maps global body motion to point motion and maps point force back to body force and moment.

Test work conjugacy:

\[
\delta q^T Q = \delta x^T f.
\]

### 8.5 Morison members between two bodies

The demonstrator braces have endpoint kinematics from separate bodies.

A straight member point is:

\[
x(s)=N_1(s)x_1+N_2(s)x_2.
\]

The fluid force is distributed back through both endpoint shape functions and both body attachment Jacobians. The mechanical stiffness of the connector is represented independently by the mechanical link, preventing hydrodynamic and structural concerns from being mixed.

#### W5 retained-block coefficient and energy criteria (adopted by the owner, 2026-10-12)

These replace the registered single-point 03c criterion "mean power at the frozen rate
within 3 % of HAMS" as a gate. That predicate measured the near-null damping eigenvector
(lambda_min/lambda_max = 5.6e-6) and is too ill-conditioned to be a sole accuracy gate
(evidence: anymarine-evidence/w5-route-comparison-20261012/REPORT.md). Its failed record is
retained unchanged. The gate lines above remain in force.

Notation, per frequency: retained matrices X in {A, B}, candidate C, reference R (HAMS
unless stated), S(X) = (X + X^T)/2, eigenpairs (lambda_k, v_k) of S(R) in decreasing order,
rho = lambda_1. Mode k is energetic when lambda_k >= 1e-3 rho, otherwise weak.
Impedance Z = B + i omega A.

- R1 full block: ||C - R||_F <= 0.03 ||R||_F for A, B and Z.
- R2 energetic modes: |v_k^T S(C) v_k - lambda_k| <= 0.03 lambda_k for every energetic k,
  for A and for B.
- R3 inter-body coupling: for the off-diagonal body-to-body sub-block, ||C_ab - R_ab||_F
  <= 0.03 ||R_ab||_F for A and B whenever ||R_ab||_F >= 1e-3 ||R||_F (else reported only).
- R4 symmetry: ||X - X^T||_F <= 0.02 ||X||_F for A and B of the candidate (reference reported).
- R5 weak modes: |v_k^T S(C) v_k - lambda_k| <= U_k, where U_k is the documented
  uncertainty of the weak eigenvalue from matched refinement and an independent route.
  Until U_k is established the weak-mode verdict is "unresolved", which does not pass W5.
- R6 near/far consistency of the candidate route: for every energetic mode u of S(B_C),
  |u^T B_C u - u^T B_far u| <= 0.03 u^T B_C u, with B_far = (4 pi rho k/(omega D))
  Re int H^* H^T d theta (analytic constant, never fitted), D = tanh kh + kh sech^2 kh.
- R7 passivity: the damping used by the time-domain model has S(B) positive semidefinite
  at every frequency, and discrete free decay never gains energy (gate line 2). The method
  is selected after the matched near-field study; eigenvalue clipping without a documented
  physical basis stays disallowed.
- R8 convergence: R1/R2 energetic measures of the candidate change by <= 1 % between two
  matched refinements with linear panel-size ratio >= 1.5.

Tolerances come from the plan's existing 2-3 % range and were fixed before evaluation.
A criterion with missing evidence is "unresolved", never "passed".

Clarifications (2026-10-12, from independent review; tolerances unchanged):
energetic reference eigenvalues closer than 1 % (relative) form a cluster, whose R2/R8
error is the spectral norm of V^T (S(C) - S(R)) V over the cluster's smallest eigenvalue
(basis-independent); R5 applies to weak modes of A as well as B; R8 measures directional
change on the fine mesh's energetic modes (not sorted eigenvalues) and needs panel counts
showing the linear ratio; retained coefficient sets must be complete and unique.

#### W5 R5 weak-mode uncertainty protocol (adopted by the owner, 2026-10-12)

Fixed before any new solve; it defines U_k for R5 on the retained 03c point (two
1 x 1 x 0.5 m boxes at x = +/-2 m, retained surge/heave, omega = 1.5 rad/s, h = 150 m).
Existing HAMS levels 4/6 show the weak damping eigenvalue moving from -9.2e-5 to +1.15e-3;
A has no weak mode there (retained eigenvalues 350-445), so R5 currently concerns B only.

- Reference series: pinned HAMS-MREL first-slice decks (anyhydro
  prepare_hams_first_slice_reference, numerical waterplane on) at subdivisions s = 6, 9, 14
  (successive linear ratios 9/6 = 1.5 and 14/9; GCI indices below). HAMS runs at the Froude-scaled native frequency of
  the manifest (same wavenumber), so no frequency-mismatch term applies.
- Mode measure: fine basis. v_k are the weak eigenvectors of S(R_14); at every level
  lambda_k(s) = v_k^T S(R_s) v_k (no eigenvalue sorting). The reference value is lambda_k(14).
- Discretization uncertainty (grid-convergence index, Celik et al. 2008, index 1 = finest):
  e21 = lambda(9) - lambda(14), e32 = lambda(6) - lambda(9), r21 = 14/9, r32 = 1.5.
  Monotone when e21 * e32 > 0; then the observed order p solves
  p = |ln|e32/e21| + q(p)| / ln r21, q(p) = ln((r21^p - s)/(r32^p - s)), s = sign(e32/e21),
  by fixed-point iteration from q = 0. If monotone and 0.5 <= p <= 4:
  U_disc = 1.25 |e21| / (r21^p - 1); otherwise U_disc = 3 |e21|.
- Output rounding: U_print = ||E_14||_2, the spectral norm of the HAMS print-rounding bound
  of the retained block at s = 14 (Weyl bound; also bounds the fixed-basis Rayleigh value).
- U_k = U_disc + U_print.
- Independent route: production Capytaine route (adapter 0.5.0) far-field Kochin damping
  B_far = (4 pi rho k/(omega D)) Re int H^* H^T dtheta (analytic constant) on the same
  first-slice hulls at s = 6, 9, 14, measured in the same fine HAMS basis v_k, with its own
  U_far from the same GCI rule (no print term).
- Guards (both required for a pass/fail verdict, otherwise R5 is "unresolved"):
  (G1) sign: U_k < |lambda_k(14)|; (G2) consistency:
  |lambda_far,k(14) - lambda_k(14)| <= U_k + U_far,k.
- Verdict: |v_k^T S(C) v_k - lambda_k(14)| <= U_k, with C the stored fine candidate
  (matrices.fine) of w5-route-comparison-20261012/criteria-capytaine-route-03.json
  (production route, quad meshes, lid z = -0.1; sha256 142777ad3c5b4028...), unchanged.

#### W5 kernel reconstruction criteria K1-K3 (adopted by the owner, 2026-10-12)

These replace, for gate line 1 ("reconstructing the frequency response from the kernel

- K1 full block: ||Z_rec - Z||_F <= 0.02 ||Z||_F, ||A_rec - A||_F <= 0.02 ||A||_F,

- K2 energetic modes: for A and for B, with the eigenpairs of S(X) at that frequency and
  the R2 energetic threshold and 1 % clustering, |v^T S(X_rec) v - lambda| <= 0.02 rho,
